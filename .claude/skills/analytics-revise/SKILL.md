# Analytics Revise

**Rules**: Follow [document-writing](../../rules/document-writing.md) and [text-formatting-ja](../../rules/text-formatting-ja.md) for Japanese documents.

## Workflow

1. **Read the existing report**: Understand current structure and content before making changes. This provides context (requirements, schema) for subsequent steps.

2. **Identify revision scope**: Clarify what needs to be revised.
   - Query changes: addition, modification, re-execution
   - Structure changes: section reorganization, flow improvement
   - Content changes: description updates, interpretation refinement

3. **Execute changes**: Make revisions while maintaining document consistency.
   - For queries: Use `/bq-query` skill (additional schema exploration if needed)
   - For structure: Ensure logical flow between sections
   - For content: Match existing writing style and tone

4. **Verify consistency**: After changes, check that the document remains coherent.
   - Updated queries match their descriptions
   - Interpretations reflect current results
   - Cross-references are valid
